# 라이선스

Unreal Engine 자체는 독점 소프트웨어입니다. 이를 사용하거나 이 프로젝트가 엔진 코드에 직접 적용한 수정 사항을 사용하려면 Epic Games에서 유효한 라이선스를 취득해야 합니다.

Angelscript 라이브러리의 소스 코드와 이 프로젝트에서 해당 코드에 직접 적용한 모든 수정 사항은 오픈 소스 [zlib 라이선스](https://www.angelcode.com/angelscript/sdk/docs/manual/doc_license.html)로 배포됩니다.

이 프로젝트의 UnrealEngine-Angelscript 플러그인 코드는 표준 MIT 오픈 소스 라이선스로 배포됩니다.

라이선스에 대한 자세한 내용은 UnrealEngine-Angelscript 프로젝트 소스에 포함된 `LICENSE.md` 파일을 참고하세요.
