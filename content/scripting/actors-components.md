# 액터와 컴포넌트
액터와 컴포넌트는 Unreal 코드의 기본적인 게임플레이 타입입니다.

스크립트에서 새 액터 또는 컴포넌트 타입을 만들려면 새 스크립트 파일을 만들고 액터 타입을 상속하는 클래스를 추가하면 됩니다.

> **참고:** 스크립트 플러그인은 모든 스크립트 클래스에 가장 유용한 클래스 플래그를 자동으로 설정합니다. 따라서 스크립트에 `UCLASS()` 지정자를 추가할 필요는 없지만, 추가 클래스 설정을 구성하려면 선택적으로 사용할 수 있습니다.

## 기본 컴포넌트
C++과 달리 스크립트 클래스는 컴포넌트를 생성할 때 생성자를 사용하지 않습니다.
액터에 기본 컴포넌트를 추가하려면 `DefaultComponent` 지정자를 사용합니다.
액터가 스폰될 때 기본 컴포넌트가 자동으로 생성됩니다.

다음 클래스를 배치하면 루트의 씬 컴포넌트와 앞서 선언한 커스텀 `UMyComponent`, 총 두 개의 컴포넌트를 갖게 됩니다.

### 블루프린트 액터 스폰
스크립트 액터 기반 클래스 대신 액터 블루프린트를 동적으로 스폰해야 하는 경우가 많습니다.
