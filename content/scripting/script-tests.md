# Angelscript 테스트 지원
Angelscript는 xUnit 스타일의 단위 테스트 프레임워크를 제공합니다. 게임 시나리오를 재생하고 특정 조건이 발생할 때까지 기다릴 수 있는 통합 테스트 프레임워크도 있습니다. 테스트 실행에 대한 코드 커버리지 보고서도 생성할 수 있습니다. `FName`

## 단위 테스트 실행
단위 테스트는 핫 리로드 시 실행됩니다. 위와 같은 테스트를 만들고 Unreal Editor를 연 뒤 파일을 저장하면 됩니다. Unreal에서 Window > Developer Tools > Output Log로 이동하면 다음과 같은 줄을 볼 수 있습니다.

```
Angelscript: [RUN]    Some.Angelscript.Subdir.Test_LaunchesNukesWhenCodesAreEntered
...
Angelscript: [OK]     Some.Angelscript.Subdir.Test_LaunchesNukesWhenCodesAreEntered (0.2530 ms)
```

또한 테스트는 Test Automation 도구의 "Angelscript" 카테고리에 표시됩니다.
이 도구는 Unreal에 설치해야 합니다. [Unreal 자동화 시스템 사용자 안내서](https://docs.unrealengine.com/en-US/Programming/Automation/UserGuide/index.html)를 참고하세요.

명령줄에서도 테스트를 실행할 수 있습니다.
```
Engine\Binaries\Win64\UE4Editor-Cmd.exe \Path\To\your.uproject -NullRHI -NoSound -NoSplash -ExecCmds="Automation RunTests Angelscript.UnitTests" -TestExit "Automation Test Queue Empty+Found 0 Automation Tests, based on" -unattended -stdout -as-exit-on-error
```

## 단위 테스트용 커스텀 게임 모드 설치
프로젝트의 `.ini` 파일 중 하나에 다음 줄을 추가하면 테스트에서 게임 모드를 사용할 수 있습니다.
그런 다음 지정된 위치에 블루프린트를 만들고 원하는 설정을 구성하세요.
모든 단위 테스트에서 이 게임 모드를 사용합니다.

```ini
[/Script/EngineSettings.GameMapsSettings]
...
+GameModeClassAliases=(Name="UnitTest",GameMode="/Game/Testing/UnitTest/BP_UnitTestGameMode.BP_UnitTestGameMode_C")
```

## 지연 자동화 명령
테스트 함수의 코드는 맵이 로드되고 첫 프레임이 실행되기 전에 실행됩니다. 따라서 테스트 함수가 반환된 시점에 테스트가 끝난 것은 아니며, 일련의 *지연 자동화 명령*([Unreal 문서](https://docs.unrealengine.com/en-US/Programming/Automation/TechnicalGuide/index.html))을 큐에 추가했을 뿐입니다. 테스트가 자체 지연 명령을 추가하지 않았다고 가정하면 테스트 프레임워크가 다음 작업을 큐에 추가합니다(`IntegrationTest.cpp` 참고).

- FWaitForMapToLoadCommand()
- FEnsureWorldLoaded()
- FExitGameCommand()
- FReportFinished()
- FFreeTest()

이 작업들은 순서대로 실행되며 각 작업은 여러 엔진 프레임에 걸쳐 실행될 수 있습니다.
