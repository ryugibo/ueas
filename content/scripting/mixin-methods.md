# 믹스인 메서드

스크립트에서는 클래스 본문 밖에서 특정 타입의 메서드를 선언할 수 있습니다.
C++ 타입에 메서드를 추가하거나 서로 다른 시스템의 기능을 분리할 때 유용합니다.

전역 함수를 `mixin` 키워드로 선언하면 됩니다.
믹스인 함수의 첫 번째 매개변수에는 이 함수를 호출한 객체가 전달됩니다.

그러면 해당 구조체를 변경할 수 있습니다.
