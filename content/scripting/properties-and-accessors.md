# 프로퍼티와 접근자
## 스크립트 프로퍼티
모든 스크립트 클래스에 변수를 선언하여 프로퍼티를 추가할 수 있습니다.
프로퍼티의 초깃값은 클래스 본문에서 지정할 수 있습니다.

기본적으로 일반 프로퍼티는 스크립트에서만 사용할 수 있으며 블루프린트나 에디터에서는 접근할 수 없습니다.

## C++ 바인딩의 프로퍼티 접근자
모든 C++ 바인딩은 별도 지정 없이 프로퍼티 접근자로 사용할 수 있습니다.
즉, `Get...()`으로 시작하는 모든 C++ 함수에 프로퍼티처럼 접근할 수 있습니다.

따라서 `Actor.ActorLocation` 같은 항목을 프로퍼티로 사용할 수 있습니다.
C++ 바인딩에서는 두 형식이 모두 유효하므로 `ActorLocation`과 `GetActorLocation()`은 같은 결과를 냅니다.

# 접근 제한자
스크립트에서 프로퍼티나 함수를 `private` 또는 `protected`로 만들려면 각 항목에 접근 제한자를 지정해야 합니다.

`private` 프로퍼티는 선언된 클래스 외부에서 전혀 접근할 수 없습니다.
`protected` 프로퍼티는 해당 클래스와 자식 클래스에서만 접근할 수 있습니다.

> **팁:** 접근 제한자는 프로퍼티뿐 아니라 함수에도 적용됩니다.
