# 함수와 BlueprintEvent
## 일반 스크립트 함수
함수는 클래스의 메서드 또는 전역 함수로 선언할 수 있습니다.
기본적으로 선언한 함수는 스크립트에서만 호출할 수 있고 블루프린트에서는 접근할 수 없습니다.

## 블루프린트에서 호출할 수 있는 함수
블루프린트에서 함수를 호출할 수 있게 하려면 함수 위에 `UFUNCTION()` 지정자를 추가합니다.

## C++의 BlueprintEvent 오버라이드 {#overriding-blueprintevents-from-c}
C++ 부모 클래스에 선언된 블루프린트 이벤트를 오버라이드하려면 `BlueprintOverride` 지정자를 사용합니다.
`BeginPlay`나 `Tick` 같은 일반적인 이벤트를 오버라이드할 때 자주 사용합니다.

Visual Studio Code 확장 프로그램은 부모 클래스의 블루프린트 이벤트를 쉽게 오버라이드할 수 있는 도우미 기능을 제공합니다.

커서가 클래스 안에 있을 때 전구 아이콘을 클릭하거나 기본 단축키 <kbd>Ctrl</kbd> + <kbd>.</kbd>를 눌러 오버라이드할 함수를 선택할 수 있습니다.

{{ img(path="override-lightbulb.png") }}

오버라이드할 수 있는 이벤트 이름을 입력하면 전체 함수 시그니처 자동 완성도 제안합니다.

{{ img(path="override-completion.png") }}

> **참고:** `ScriptName` 메타 태그를 명시하지 않은 C++ 함수에는 이름 단순화가 자동으로 적용되어 일반적인 접두사가 제거됩니다.
> 예를 들어 C++ 이벤트 이름은 `ReceiveBeginPlay`이지만 앞의 `Receive`가 제거되어 스크립트에서는 `BeginPlay`가 됩니다.
> 그 밖에 `BP_`, `K2_`, `Received_` 접두사도 자동으로 제거됩니다.

## 블루프린트에서 스크립트 함수 오버라이드
스크립트 부모 클래스를 상속하는 블루프린트를 만들어야 하는 경우가 많습니다.
자식 블루프린트에서 함수를 오버라이드할 수 있게 하려면 `BlueprintEvent` 지정자를 추가합니다.

> **참고:** 스크립트에서는 C++처럼 `BlueprintImplementableEvent`와 `BlueprintNativeEvent`를 구분하지 않습니다.
> 모든 스크립트 함수에는 부모 구현이 필요하지만 비워 둘 수 있습니다.

### 팁: 블루프린트 이벤트 분리
Unreal에서는 부모 이벤트와 블루프린트 이벤트를 분리하는 패턴을 자주 사용합니다.
이렇게 하면 자식 블루프린트 노드와 함께 스크립트 코드가 항상 실행되도록 보장할 수 있으며, 블루프린트에서 "부모 함수 호출 추가"를 하지 않아 발생하는 문제도 피할 수 있습니다.

## 전역 함수
전역 범위의 모든 스크립트 함수에도 `UFUNCTION()`을 추가할 수 있습니다.
그러면 모든 블루프린트에서 정적 함수처럼 호출할 수 있습니다.

블루프린트 함수 라이브러리와 비슷하게 클래스에 속하지 않는 함수를 만들 수 있습니다.

## 부모 메서드 호출
다른 스크립트 함수로 스크립트 함수를 오버라이드할 때는 Unreal과 동일한 `Super::` 문법으로 부모 함수를 호출할 수 있습니다.
스크립트 메서드는 부모 함수에 `BlueprintEvent`가 없어도 오버라이드할 수 있습니다. 모든 스크립트 메서드가 가상이기 때문입니다. 단, `BlueprintEvent`를 오버라이드할 때는 오버라이드 함수에 `BlueprintOverride`를 지정해야 합니다.
